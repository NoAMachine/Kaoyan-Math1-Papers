# 2009 年数学一解答题第 16 题

(16)(本题满分9分)

设 $a_{n}$ 为曲线 $y = x^{n}$ 与 $y = x^{n + 1}(n = 1,2,\dots)$ 所围成区域的面积，记 $S_{1} = \sum_{n = 1}^{\infty}a_{n},S_{2} = \sum_{n = 1}^{\infty}a_{2n - 1}$ 求 $S_{1}$ 与 $S_{2}$ 的值.
