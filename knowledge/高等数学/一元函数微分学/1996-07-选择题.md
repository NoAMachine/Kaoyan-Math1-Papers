# 1996 年数学一选择题第 7 题

（2）设 $f(x)$ 有二阶连续导数，且 $f^{\prime}(0) = 0,\lim_{x\to 0}\frac{f^{\prime\prime}(x)}{|x|} = 1$ ，则（ ）.

(A) $f(0)$ 是 $f(x)$ 的极大值  
(B) $f(0)$ 是 $f(x)$ 的极小值  
(C) $(0, f(0))$ 是曲线 $y = f(x)$ 的拐点  
(D) $f(0)$ 不是 $f(x)$ 的极值， $(0,f(0))$ 也不是曲线 $y = f(x)$ 的拐点
