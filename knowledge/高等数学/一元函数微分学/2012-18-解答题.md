# 2012 年数学一解答题第 18 题

(18)(本题满分10分)

已知曲线 $L:\left\{ \begin{array}{l}x = f(t),\\ y = \cos t \end{array} \right.$ ，其中函数 $f(t)$ 具有连续导数，且 $f(0) = 0,f^{\prime}(t) > 0$ （ $0 <   t <   \frac{\pi}{2})$ 若曲线 $L$ 的切线与 $x$ 轴的交点到切点的距离恒为1,求函数 $f(t)$ 的表达式，并求以曲线 $L$ 及 $x$ 轴和 $y$ 轴为边界的区域的面积.
