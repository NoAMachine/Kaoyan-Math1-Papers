$$

$= \iiint _ { \Omega } ( 1 + 1 + 1 ) \mathrm { d } \nu = 3 \iiint _ { \Omega } \mathrm { d } \nu = 3 \cdot { \frac { 1 } { 3 } } \pi { \left( { \frac { \sqrt { 2 } } { 2 } } \right) } ^ { 2 } { \left( { \frac { \sqrt { 2 } } { 2 } } \right) } = { \frac { \sqrt { 2 } } { 4 } } \pi$ (注： $\Omega$ 为圆 锥体 ) 。
