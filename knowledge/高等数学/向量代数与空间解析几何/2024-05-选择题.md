# 2024 年数学一选择题第 5 题

【5】在空间直角坐标系 $O - x y z$ 中，三张平面 $\pi _ { i } : a _ { i } x + b _ { i } y + c _ { i } z = d _ { i } $ $i = 1 , 2 , 3 )$ 位置关系如图所示, 记 $\pmb { \alpha } _ { i } = ( a _ { i } , b _ { i } , c _ { i } ) , \pmb { \beta } _ { i } = ( a _ { i } , b _ { i } , c _ { i } , d _ { i } )$ ,若 $r \left( \begin{array} { l } { \pmb { \alpha } _ { 1 } } \\ { \pmb { \alpha } _ { 2 } } \\ { \pmb { \alpha } _ { 3 } } \end{array} \right) = m , r \left( \begin{array} { l } { \pmb { \beta } _ { 1 } } \\ { \pmb { \beta } _ { 2 } } \\ { \pmb { \beta } _ { 3 } } \end{array} \right) = n$ , 则

（A） $m = 1 , n = 2$   
（B） $m = n = 2$   
（C） $m = 2 , n = 3$   
（D） $m = n = 3$
