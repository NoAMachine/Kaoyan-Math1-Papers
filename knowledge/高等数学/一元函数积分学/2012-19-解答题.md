# 2012 年数学一解答题第 19 题

(19)(本题满分10分)

已知 $L$ 是第一象限中从点 $(0,0)$ 沿圆周 $x^{2} + y^{2} = 2x$ 到点 $(2,0)$ , 再沿圆周 $x^{2} + y^{2} = 4$ 到点 $(0,2)$ 的曲线段, 计算曲线积分 $I = \int_{L}3x^{2}y\mathrm{d}x + (x^{3} + x - 2y)\mathrm{d}y.$
