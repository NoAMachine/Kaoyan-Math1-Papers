# 2024 年数学一选择题第 1 题

【1】已知函数 $f ( x ) = \int _ { 0 } ^ { x } \mathbf { e } ^ { \cos t } \mathrm { d } t$ ， $g ( x ) = \int _ { 0 } ^ { \sin x } \mathbf { e } ^ { t ^ { 2 } } \mathrm { d } t$ ，则

（A） $f ( x )$ 为奇函数， $g ( x )$ 为偶函数.

（B） $f ( x )$ 为偶函数， $g ( x )$ 为奇函数.

（C） $f ( x )$ 与 $g ( x )$ 均为奇函数.

（D） $f ( x )$ 与 $g ( x )$ 均为偶函数.
