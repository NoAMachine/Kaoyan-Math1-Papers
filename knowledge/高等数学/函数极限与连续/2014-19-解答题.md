# 2014 年数学一解答题第 19 题

(19)(本题满分10分)

设数列 $\{a_{n}\},\{b_{n}\}$ 满足 $0 < a_{n} < \frac{\pi}{2}, 0 < b_{n} < \frac{\pi}{2}, \cos a_{n} - a_{n} = \cos b_{n}$ , 且级数 $\sum_{n=1}^{\infty} b_{n}$ 收敛.

(I) 证明 $\lim_{n \to \infty} a_n = 0$ ;  
（Ⅱ）证明级数 $\sum_{n = 1}^{\infty}\frac{a_n}{b_n}$ 收敛.
