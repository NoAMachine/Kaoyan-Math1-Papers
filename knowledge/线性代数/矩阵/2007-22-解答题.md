# 2007 年数学一解答题第 22 题

(22)(本题满分11分)

设3阶实对称矩阵 $\mathbf{A}$ 的特征值 $\lambda_{1} = 1, \lambda_{2} = 2, \lambda_{3} = -2$ ，且 $\pmb{\alpha}_{1} = (1, -1, 1)^{\mathrm{T}}$ 是 $\mathbf{A}$ 的属于 $\lambda_{1}$ 的一个特征向量. 记 $\pmb{B} = \pmb{A}^{5} - 4\pmb{A}^{3} + \pmb{E}$ ，其中 $\pmb{E}$ 为3阶单位矩阵.

(I) 验证 $\alpha_{1}$ 是矩阵 $\pmb{B}$ 的特征向量, 并求 $\pmb{B}$ 的全部特征值与特征向量;  
（Ⅱ）求矩阵 $\pmb{B}$
