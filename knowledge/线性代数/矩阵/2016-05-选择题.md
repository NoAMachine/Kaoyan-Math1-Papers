# 2016 年数学一选择题第 5 题

(5) 设 $A, B$ 是可逆矩阵，且 $A$ 与 $B$ 相似，则下列结论错误的是（）

(A) $A^{\mathrm{T}}$ 与 $\pmb{B}^{\mathrm{T}}$ 相似.

(B) $A^{-1}$ 与 $\pmb{B}^{-1}$ 相似

(C) $A + A^{\mathrm{T}}$ 与 $\boldsymbol{B} + \boldsymbol{B}^{\mathrm{T}}$ 相似.

$(\mathrm{D})\pmb {A} + \pmb{A}^{-1}$ 与 $\pmb {B} + \pmb{B}^{-1}$ 相似
