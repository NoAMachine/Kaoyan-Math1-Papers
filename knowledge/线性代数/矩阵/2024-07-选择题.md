# 2024 年数学一选择题第 7 题

【7】设 $\pmb { A }$ 是秩为 2 的 3 阶矩阵, $\pmb { \alpha }$ 是满足 $\mathbf { A } \mathbf { \alpha } \mathbf { \alpha } { = } \mathbf { 0 }$ 的非零向量，若对满足 $\pmb { \beta } ^ { \mathrm { T } } \pmb { \alpha } = \pmb { 0 }$ 的任意向量 $\pmb { \beta }$ ，均有 $A { \pmb \beta } = { \pmb \beta }$ ，则

（A） $A ^ { 3 }$ 的迹为 2.

（B） $A ^ { 3 }$ 的迹为 5.

（C） $A ^ { 5 }$ 的迹为 7.

（D） $A ^ { 5 }$ 的迹为 9.
