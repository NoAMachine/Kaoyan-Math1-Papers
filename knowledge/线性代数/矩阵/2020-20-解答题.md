# 2020 年数学一解答题第 20 题

（20）（本题满分11分）

设二次型 $f(x_{1},x_{2}) = x_{1}^{2} - 4x_{1}x_{2} + 4x_{2}^{2}$ 经正交变换 $\binom{x_1}{x_2}=\mathbf{Q}\binom{y_1}{y_2}$ 化为二次型 $g(y_{1},y_{2}) = ay_{1}^{2} + 4y_{1}y_{2} + by_{2}^{2}$ ，其中 $a\geqslant b$

（I）求 $a, b$ 的值；  
（Ⅱ）求正交矩阵 $Q$
