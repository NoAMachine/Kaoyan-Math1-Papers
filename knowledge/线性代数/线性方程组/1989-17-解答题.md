# 1989 年数学一解答题第 17 题

问 $\lambda$ 为何值时，线性方程组 $\left\{ \begin{array}{l} x_{1} + x_{3} = \lambda, \\ 4x_{1} + x_{2} + 2x_{3} = \lambda + 2, \\ 6x_{1} + x_{2} + 4x_{3} = 2\lambda + 3 \end{array} \right.$ ，有解，并求出解的一般形式.
