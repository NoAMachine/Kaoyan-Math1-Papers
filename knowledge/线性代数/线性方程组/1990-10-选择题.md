# 1990 年数学一选择题第 10 题

（5）已知 $\beta_{1},\beta_{2}$ 是非齐次线性方程组 $AX = b$ 的两个不同解， $\alpha_{1},\alpha_{2}$ 是对应的齐次线性方程组 $AX = 0$ 的基础解系， $k_{1},k_{2}$ 为任意常数，则方程组 $AX = b$ 的通解为（ ）.

(A) $k_{1}\pmb{\alpha}_{1} + k_{2}(\pmb{\alpha}_{1} + \pmb{\alpha}_{2}) + \frac{\pmb{\beta}_{1} - \pmb{\beta}_{2}}{2}$   
(B) $k_{1}\pmb{\alpha}_{1} + k_{2}(\pmb{\alpha}_{1} - \pmb{\alpha}_{2}) + \frac{\pmb{\beta}_{1} + \pmb{\beta}_{2}}{2}$   
(C) $k_{1}\pmb{\alpha}_{1} + k_{2}(\pmb{\beta}_{1} + \pmb{\beta}_{2}) + \frac{\pmb{\beta}_{1} - \pmb{\beta}_{2}}{2}$   
(D) $k_{1}\pmb{\alpha}_{1} + k_{2}(\pmb{\beta}_{1} - \pmb{\beta}_{2}) + \frac{\pmb{\beta}_{1} + \pmb{\beta}_{2}}{2}$
