# 2017 年数学一解答题第 22 题

(22) (本题满分 11 分)

设随机变量 $X, Y$ 相互独立，且 $X$ 的概率分布为 $P\{X = 0\} = P\{X = 2\} = \frac{1}{2}, Y$ 的概率密度为 $f(y) = \left\{ \begin{array}{ll} 2y, & 0 < y < 1, \\ 0, & \text{其他}. \end{array} \right.$

(I) 求 $P\{Y \leqslant E(Y)\}$ ;   
（Ⅱ）求 $Z = X + Y$ 的概率密度
