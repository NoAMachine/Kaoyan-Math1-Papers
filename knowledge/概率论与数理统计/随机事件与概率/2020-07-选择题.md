# 2020 年数学一选择题第 7 题

7）设 $A, B, C$ 为三个随机事件，且 $P(A) = P(B) = P(C) = \frac{1}{4}, P(AB) = 0,$ $P(AC) = P(BC) = \frac{1}{12}$ ，则 $A, B, C$ 中恰有一个事件发生的概率为（ ）.

(A) $\frac{3}{4}$

(B) $\frac{2}{3}$

(C) $\frac{1}{2}$

(D) $\frac{5}{12}$
