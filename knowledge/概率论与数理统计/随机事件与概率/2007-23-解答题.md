# 2007 年数学一解答题第 23 题

(23) (本题满分 11 分)

设二维随机变量 $(X,Y)$ 的概率密度为

$$
f (x, y) = \left\{ \begin{array}{l l} 2 - x - y, & 0 <   x <   1, 0 <   y <   1, \\ 0, & \text {其 他}. \end{array} \right.
$$

(I)求 $P\{X > 2Y\}$   
（Ⅱ）求 $Z = X + Y$ 的概率密度 $f_{Z}(z)$
