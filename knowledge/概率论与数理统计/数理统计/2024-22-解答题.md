# 2024 年数学一解答题第 22 题

【22】 （本题满分 12分）

设 总 体 $X \sim U ( 0 , \theta )$ ， $\theta$ 未 知 ， $X _ { 1 } , X _ { 2 } \cdots X _ { n }$ 为 简 单 随 机 样 本 ，$X _ { _ { ( n ) } } = \operatorname* { m a x } ( X _ { _ { 1 } } , X _ { _ { 2 } } \cdots X _ { _ { n } } ) , ~ T _ { _ c } = c X _ { _ { ( n ) } } .$

（1）求 $c$ 时，使得 $T _ { c }$ 为 $\theta$ 的无偏估计.  
（2）记 $h ( c ) = E ( T _ { c } - \theta ) ^ { 2 }$ ，求 $c$ 使得 $h ( c )$ 取最小值.
